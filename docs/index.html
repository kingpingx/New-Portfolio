ThePlayer

v1.0 · Feature complete

Plays RTSP cameras and H.265 video in Chrome, and lets you pick where the decoding happens.

  • Where it decodesServer load
  • On the clientWebSocket → WebCodecs · original bytes
  • Server assistedWebRTC via MediaMTX · H.265 → H.264 when needed
  • On the serverWebSocket JPEG frames · 5–10× the bandwidth

Browsers speak neither RTSP nor, in most cases, H.265. ThePlayer solves the transport with MediaMTX and a WebSocket, then offers three answers to the codec problem from one shared FFmpeg process. If the browser can decode H.265 itself, it gets the original bytes and the server's encoder sits at zero. The page shows what each choice costs on both ends while the video plays.

  • .NET 8
  • FFmpeg
  • MediaMTX
  • WebRTC
  • WebCodecs
  • Angular

An Angular virtual tree that stays fast at 100,000 nodes.

It records the hierarchy as metadata, flattens it to visible rows, then windows the list, so about 30 rows exist in the DOM however big the tree gets. Tri-state checkboxes, drag and drop, and full ARIA tree support. Built on Gabriel J. Campbell's of-tree.
